# LAWSTART

Информационный навигатор по юридическому образованию Казахстана и зарубежных университетов. Помогает абитуриентам, студентам, выпускникам и родителям ориентироваться в юридическом образовании.

## Разделы

- Юридическое образование Казахстана
- Бакалавриат
- Второе высшее
- Магистратура
- Зарубежное образование и LL.M.
- Legal English
- LAWSTART INDEX — короткий тест, помогающий выбрать, с какого раздела начать

## Каталог

Поиск образовательных программ по университету, городу, уровню образования, программе и коду ОП. В каталоге 52 вуза и 182 программы (включая смежные направления, например 6B123).

Запись каталога не равна проверенной программе. Карточки с отметкой «Сверено с сайтом вуза» сверены с официальной страницей вуза, дата сверки указана в карточке. Остальные карточки проверяются.

## Источники и ограничения

Данные собраны из открытых источников, в первую очередь с официальных сайтов университетов, а также из государственных ресурсов (Национальный центр тестирования, реестр образовательных программ epvo.kz). Условия приёма, сроки обучения, стоимость и госзаказ могут меняться: перед подачей документов проверяйте актуальные данные на сайте вуза.

Госзаказ размещается по группам образовательных программ (B049, M078), а не по отдельным программам.

LAWSTART — информационный навигатор, а не государственный орган, университет или приёмная комиссия.
